## Using them

- Prefer the objects whose size varies least: people, steps, doors.
- Check one cue against another. If a door says 2 m and a person beside it says 3 m, one reading is wrong.
- In stylized or AI-generated references, scale cues can conflict on purpose: a giant door to dwarf a figure. Decide which reading is the intent, and state it.
