# Style decides the method

Decide the style category first. It decides where you may bend physics. It never decides whether a phenomenon is modelled.

| | Stylized / illustrated / dreamlike | Photographic, or no reference |
|---|---|---|
| Authority | The image alone | Real footage |
| Geometry | Realistic modelling, true shapes, coherent space | Same |
| Phenomena (water, clouds, plants) | Still modelled as the real thing (FFT water, volumetric clouds, real trees). Simplify the shading, not the method. | Modelled at full physical fidelity |
| Light | May ignore occluders, hold the sky down, add fills with no physical source, use an impossible key, subtly and via lights | Physical light transport. One sun, a physical sun-to-sky ratio. |
| Grade | May push palette and contrast to the reference | Restrained. Lens and sensor traits: lateral chromatic aberration, shadow-weighted noise, vignette. |
| Bloom | Matches the reference's glow | Veiling glare only |
| Variation | Matches the reference | Natural variation between individuals, never clones |

## The anchor principle

A strong, realistic base anchors the image in reality. The deliberate deviation carries it past reality to the reference's beauty. Without the base, a stylized scene looks like a cheap cartoon, not like the reference. If you deviate everywhere, nothing reads as intentional.

## Preserving the impossibility

Some references are beautiful because of an impossibility. Examples: a normal room with the ceiling swapped for water, with nothing else changed; a cloud hundreds of kilometres across inside a small room; a building lit as though its neighbours weren't there.

- **Identify the impossibility.** Ask what the image would lose if it were made physically consistent.
- **Keep it, and confine it.** In the water-ceiling case, the room is rendered exactly as if the ceiling were solid. The water does not light or interact with the room, because that interaction is what would break the effect.
- **Keep every other layer coherent:** geometry, the other light paths, scale everywhere else.
- **Check that it holds from all angles.** If an art-directed effect breaks when the viewer orbits, it is a defect, not a style. A typical case: a building row lit as though it cast no shadow, while the sun visibly sits behind its towers. Then find the physically consistent setup that gives the same look from the hero view, for example a sun position that throws the shade where the reference has it.

## Dreamlike and liminal

For dreamcore and liminal spaces, the appeal comes from implausibility: scale, causality and light bent on purpose. Mix a realistic render with chosen impossible elements. Getting every scale and causal chain correct destroys the appeal. Getting nothing correct reads as a cartoon. Read the reference to see which is which.
